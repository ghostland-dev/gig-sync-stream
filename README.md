# GigSync

Centralises freelance messages from Fiverr, Upwork, Malt and Codeur.

## Features

- Unified inbox
- Clients, drafts and archives
- Statistics

## Tech Stack

- Vite
- React
- TypeScript
- Tailwind CSS
- shadcn/ui (Radix UI)
- TanStack Query
- React Router

## Getting Started

```bash
git clone https://github.com/ghostland-dev/gig-sync-stream.git
cd gig-sync-stream
npm install
npm run dev
```

Other scripts:

- `npm run build`: vite build
- `npm run lint`: eslint .
- `npm run preview`: vite preview
